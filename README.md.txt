# Invoice Dashboard Project

This is a real-world data project analyzing invoices for customers and products.

## Dataset
The dataset includes the following columns:
- invoice_id
- customer_code
- product_code
- quantity
- unit_price
- total_buy (calculated as quantity * unit_price)
- invoice_date

## Project Overview
- Import data from PostgreSQL
- Perform basic data cleaning and EDA
- Create measures like Total Sales, Units Sold, and Number of Customers
- Build visual dashboards in Power BI:
  - Top 10 products by income
  - Top 5 customers by total purchases
  - KPI cards for key metrics

## Tools
- PostgreSQL for data storage and queries
- Power BI for visualization
- Excel (if needed for additional cleaning)

## Purpose
This project demonstrates data analysis and visualization skills using real-world invoice data. It can be used as a portfolio piece to showcase SQL and Power BI knowledge.
